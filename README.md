# Coffio

**Coffio** is a modern Android application designed for coffee enthusiasts to track, analyze, and perfect their brewing process.

## Features

- **☕ Brewing Tracker:** Log your daily brews and maintain consistency.
- **📊 Detailed Charts:** Visualize your brewing data and trends over time.
- **📜 History:** Keep a comprehensive record of all your past coffee sessions.
- **⚙️ Customization:** Adjust settings to fit your personal brewing style.

## Technologies Used

- **Jetpack Compose:** For a modern, declarative UI.
- **Kotlin:** The primary programming language.
- **Material 3:** Modern design system for a sleek look and feel.

## Optional LAN Sync Server

Server stack is optional and moved to [CoffServer/README.md](CoffServer/README.md).
Use that guide when you want multi-device sync on your local network.
